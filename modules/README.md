# Smart Utility Toolkit


Built using only Node.js core modules: `process`, `http`, `fs`, `crypto`.

## How to Run Each Part

### 1. CLI Calculator
node calculator.js add 10 5
node calculator.js sub 20 8
node calculator.js mul 4 5
node calculator.js div 10 2

### 2. Custom Module Reuse (isEven + logger)
node app.js

### 3. HTTP Server
node server.js
Then open: http://localhost:3000/ , /about , /contact

### 4. File Manager (Create, Read, Update, Delete)
node fileManager.js

### 5. Dice Generator
node dice.js
